SCAN_TO_LAUNCH

Open this on your phone

— OBJECT —

Scan with your phone's camera. It'll open this object directly and AR will launch automatically — no app required.

How this works — each <model-viewer> tag loads a .glb file and renders it with WebGL. On mobile, "View in AR" calls activateAR() directly, which checks WebXR → Scene Viewer → Quick Look in order. On desktop, the same button instead shows a QR code pointing to this same page with a ?model= parameter — scanning it opens the page on your phone and auto-triggers AR for that object once it's loaded.

Important: this QR flow only works once the page is hosted over HTTPS (e.g. Firebase Hosting, GitHub Pages, Netlify). AR cannot launch from a local file:// path or plain HTTP.

To swap in your own model — replace the src attribute with a path to your .glb, and add ios-src="yourmodel.usdz" if you want Quick Look support on iPhone.
